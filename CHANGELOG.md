# Changelog

## 1.0.0 (2026-11-17)

Packaged for distribution, matching the layout of `app-security-audit`.

- **Install paths:** Claude Code plugin (`.claude-plugin/plugin.json`, `marketplace.json`, icon), a dependency-free `npx anti-ai-writing` installer for Claude Code, Cursor, VS Code (GitHub Copilot), Codex, Gemini CLI, Windsurf, OpenCode and `.agents`, and the Skills CLI (`npx skills add savicsly/anti-ai-writing`).
- **Layout:** `reference/` renamed to `references/` to follow the Agent Skills convention; all links updated.
- **SKILL.md:** one H1 with H2 sections, so the outline is easier for agents and readers to follow. No rule changes.
- **Repo:** `package.json`, `RELEASING.md`, wider `.gitignore`, README rewritten around the install options.

## 2026-10 refresh

- **SKILL.md:** sharper trigger description; added Rewrite / Review-only / Light-touch modes; added a protected-content list (legal clauses, figures, names, IDs, quotes, code); added a working method with a verify step; stated that detectors are unreliable and not a target; added a "never invent" rule.
- **detection-and-models.md:** replaced the stale model table with a 2025 to 2026 signal-reliability view (per-family em dash data, markdown density, decay of word tells); added detector and homogenisation cautions; added new sources (Pangram 9 signs, Wikipedia editors' guide, tropes.fyi, UWA 2026).
- **vocabulary.md:** added 2025 to 2026 patterns (intensifier adverbs, ornate nouns, pompous verb swaps, hazy "-ing" clauses, invented labels, performed candour) plus a handle-with-care note.
- **sentence-and-rhythm.md:** added newer structural tells (contrast framing variants, default triads, fragment paragraphs, hand-holding, disguised numbering, self-posed questions, fractal summaries).
- **formatting-and-punctuation.md:** revised em dash guidance (weak, model-dependent signal); added markdown, bold, header, Unicode and emoji data points and a genre-context test.
- **New: business-and-agency-writing.md:** proposals, lead replies, payment reminders, status updates, case studies, agency websites, regional business register, and what never to rewrite.

Frequency figures from Pangram are vendor data and indicative only; sources are listed in detection-and-models.md.
